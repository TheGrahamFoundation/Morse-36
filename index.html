MORSE/36

Compact Machine Intent

Machines should transmit intent, not representation.
Morse/36 is an open protocol exploring how machines with shared deterministic semantics can communicate using compact Morse words.

Explore the protocolRead RFC-0001
THE IDEA
Morse/36 does not compress content.
Morse/36 compacts intent.
DLM ↔ DLM

The wire carries the Morse.

Applications can keep their rich internal representations: JSON, XML, YAML, HL7, objects, semantic graphs or state. A deterministic model resolves the desired machine intent into a Morse. The receiving deterministic model resolves that Morse into a permitted action.

DLM ADomain state → semantic resolution → Morse
FTIPON THE WIRE
DLM BMorse → deterministic resolution → action
HEALTHCARE

Representation can stay behind the boundary.

A healthcare application may internally use HL7. Morse/36 does not claim HL7 is unnecessary. It asks whether an entire representation must cross a machine boundary when the receiver already possesses the relevant state and only needs the intended operation. If new information is required, those bits must still travel or be referenced. Morse/36 does not pretend information theory disappears.

1%
THE 1% PRINCIPLE

Measure first. Claim second.

If Morse/36 can reproducibly reduce resources by even 1% for suitable machine-intent workloads without sacrificing semantic fidelity, interoperability, reliability or safety, that is useful. If the benchmark says zero, we publish zero. If it says one percent, that one percent belongs to everyone.

OPEN PROTOCOL

Come challenge it.

Morse/36 is discussion-first and open. Break the assumption. Bring a domain. Propose semantics. Design a registry. Build an encoder. Challenge the benchmark. The specification and reference implementations should never require proprietary Foundation or David Labs infrastructure.
